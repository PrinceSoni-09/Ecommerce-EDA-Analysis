# E-Commerce Data Analysis

## Objective

Perform exploratory data analysis on an e-commerce dataset to understand customer behavior, sales performance, and business trends.

## Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook
* Excel

## Analysis Performed

* Dataset overview and inspection
* Statistical summary of key variables
* Product sales analysis
* Payment method analysis
* Order status distribution
* Revenue analysis
* Outlier identification
* Referral source analysis

## Key Findings

* Identified top-performing products based on sales.
* Examined customer payment preferences.
* Analyzed order completion and cancellation trends.
* Evaluated revenue patterns across transactions.
* Explored customer acquisition sources and business insights.

## Conclusion

The analysis provided valuable insights into sales performance, customer preferences, and operational trends. Visualizations and summary statistics were used to support data-driven business decisions.
